 💊 Medisync

Medisync is a simple healthcare management web app made to connect patients and doctors easily.  
It helps store and view patient details, appointments, and reports using a modern and clean interface.

🌟 Features
- Patient and doctor dashboards  
- Easy appointment management  
- Simple and responsive design  
- Java JDBC database connection for data storage  
- Works on web and can be extended for mobile  

 🧰 Tech Stack
Frontend: React + Vite  
tyling: Tailwind CSS 
Backend: Java JDBC  
Database: MySQL
